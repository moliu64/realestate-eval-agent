# 房地产估价 FAQ

## 资料不完整可以估价吗

可以进行有限条件下的估价，但必须说明资料缺失情况、采用的假设和可能影响。关键权属、面积、用途或租约资料无法核实时，估价结果的不确定性会明显增加，不应把估价结论表达为无条件确定值。

## 为什么同一套房不同机构估价不同

估价差异可能来自估价目的、估价时点、资料来源、可比实例选择、参数判断和风险假设不同。只要方法合理、依据充分、过程可追溯，估价结果在合理区间内存在差异是正常的。

## 估价结果等于成交价吗

估价结果不必然等于最终成交价。成交价受谈判能力、付款方式、交易急迫程度、税费承担、装修家具、市场情绪等因素影响。估价结果反映特定估价目的和估价时点下的专业价值判断。

## RAG 问答适合解决什么问题

RAG 问答适合回答有明确知识依据的问题，例如估价方法定义、适用条件、报告要件和参数解释。对于需要实时市场价格、具体楼盘成交数据或法律税务最终认定的问题，应接入外部数据源或人工复核。

## 面试演示时如何讲清楚

可以按“用户提问、知识库检索、上下文注入、模型生成、来源引用”五步讲解。重点强调本地 embedding 与 chat 模型分离、回答必须引用来源、没有依据时诚实说明，这能体现工程可控性和风险意识。
